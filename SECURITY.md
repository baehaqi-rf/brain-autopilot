# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `2.0.x` | Yes |
| `< 2.0` | No |

## Reporting a Vulnerability

If you discover a security vulnerability in **Brain Autopilot** (for example, in credential redaction, CDP/ADB command handling, or MCP server execution), please **do not** open a public GitHub issue.

Instead, please report it privately using **GitHub Security Advisories**:

1. Go to the repository's **Security** tab on GitHub.
2. Click **Report a vulnerability**.
3. Provide a clear description, steps to reproduce, and potential impact.

We will acknowledge receipt of your report as soon as possible and work with you to validate and resolve the issue before any public disclosure.
